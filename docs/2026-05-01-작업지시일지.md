### [BUG-03] STEP 4 — 스토캐스틱 로직 누락 / `high`, `low` 미사용 변수

- **파일**: `calc_tech_score()`
- **원인**: 가이드 문서에 명시된 스토캐스틱 신호가 알고리즘에서 구현되지 않음. `high`, `low` 변수가 선언만 되고 사용되지 않음
- **수정 방향**:
  ```python
  # 스토캐스틱 추가 (pandas_ta 사용)
  stoch = ta.stoch(high, low, close, k=14, d=3)
  stoch_k = stoch['STOCHk_14_3_3']
  stoch_d = stoch['STOCHd_14_3_3']

  # 과매도(20 이하) 탈출 + K/D 골든크로스 (최대 2점)
  if stoch_k.iloc[-2] < stoch_d.iloc[-2] and stoch_k.iloc[-1] >= stoch_d.iloc[-1]:
      if stoch_k.iloc[-1] < 50:  # 과열 구간 제외
          score += 2; signals.append(f"스토캐스틱 골든크로스 ({stoch_k.iloc[-1]:.1f})")
  ```
- **담당**: 백엔드 개발
- **완료 기준**: 스토캐스틱 점수 정상 반영 + `high`, `low` 변수 활용
