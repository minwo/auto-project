## 오늘 재개할 핵심 작업

같은 종목이 여러 거래일에 연속으로 추천될 경우, 각 날짜를 독립 추천으로 보지 말고 **첫 추천일 기준으로 수익률을 누적 계산**한다.

예시:

- 2026-04-29: DL 첫 추천, 기준가 76,800원
- 2026-04-30: DL 연속 추천, 당일 종가는 71,500원
- 현재 화면 문제: 2026-04-30 행이 71,500원을 새 기준가로 잡아 수익률 0.00%로 표시됨
- 기대 동작: 2026-04-30 행도 2026-04-29의 76,800원을 기준가로 사용해 약 -6.90%로 표시하고, `연속 2일` 같은 표시를 제공

## 미완료 작업 ID

### [TOPPICK-01] 연속 추천 종목 수익률 기준일 고정

- **상태**: 미완료
- **우선순위**: 높음
- **문제**: `daily_top_score_picks`는 날짜별 최고 점수 종목을 저장하지만, 화면 추적 수익률은 같은 종목이 연속 추천되어도 매일 새 기준가로 다시 계산된다.
- **목표**: 같은 종목이 전일에 이어 다시 추천되면, 해당 연속 구간의 첫 추천일 종가를 기준가로 유지한다.
- **완료 기준**:
  - 같은 종목의 연속 추천 구간을 식별한다.
  - 연속 구간의 첫 추천일을 `streakStartDate`로 반환한다.
  - 연속 추천 일수를 `streakDays`로 반환한다.
  - 연속 추천 여부를 `isContinued`로 반환한다.
  - 화면의 `baseClose`와 `changePct`는 연속 구간의 첫 추천 기준으로 계산한다.
  - 당일 자체 기준가는 필요 시 `dailyBaseClose`로 별도 반환한다.

### PostgreSQL 조회 로직

`get_daily_top_picks()`에서 날짜 오름차순 기준으로 연속 구간을 계산한다.

권장 SQL 흐름:

1. `daily_top_score_picks`를 `pick_date ASC`로 정렬한다.
2. `LAG(code)`로 직전 추천 종목을 확인한다.
3. 직전 종목과 현재 종목이 다르면 새 구간으로 본다.
4. 누적 `SUM()`으로 `streak_group`을 만든다.
5. `FIRST_VALUE(base_close)`로 연속 구간의 첫 기준가를 가져온다.
6. `ROW_NUMBER()`로 `streakDays`를 계산한다.
7. 최종 응답은 기존처럼 `pick_date DESC`로 반환한다.

수익률 계산 기준:

```python
base_close = streak_base_close
change_pct = ((latest_close - base_close) / base_close) * 100
```

### 인메모리 저장소

테스트용 `CandidateRepository.refresh_daily_top_picks()`도 같은 규칙을 따른다.

- 직전 날짜 top pick과 현재 top pick의 `code`가 같으면 연속 추천으로 처리
- `base_close`는 직전 연속 구간의 첫 기준가 유지
- `daily_base_close`는 현재 날짜의 종가 저장
- `streak_days`는 1씩 증가
