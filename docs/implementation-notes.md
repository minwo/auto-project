# 구현 메모

## 이번 스캐폴드의 목적

현재 저장소에는 설계 문서만 있었기 때문에, 바로 개발을 이어갈 수 있도록 MVP 백엔드의 최소 실행 구조를 먼저 만들었습니다.

이 구현은 다음을 목표로 합니다.

- 설계안의 룰이 코드 레벨에서 명확히 읽힐 것
- 실제 데이터 소스만 연결하면 배치/백테스트로 확장 가능할 것
- 사용자 노출용 후보 API와 내부 분석용 상세 API가 분리될 것

## 반영된 설계안

### 1. 유니버스 필터

`app.scoring.is_eligible`에서 아래 조건을 제외합니다.

- KOSPI/KOSDAQ 외 시장
- 보통주 외 종목
- ETF/ETN
- 우선주
- 스팩
- 관리종목
- 거래정지
- 상장 60거래일 미만
- 최근 20거래일 평균 거래대금 10억원 미만

### 2. 점수 엔진

`app.scoring.evaluate_snapshot`는 아래 구성으로 총점을 계산합니다.

- 수급/거래대금 확대 25점
- 종가 강도 20점
- 재료/이벤트 20점
- 섹터 동조성 15점
- 추세 연속성 10점
- 리스크 패널티 최대 -30점

최종 점수는 0~100으로 클램프합니다.

### 3. 후보 선정 규칙

`app.repository.select_top_candidates`는 아래 조건을 적용합니다.

- 점수 내림차순 정렬
- 60점 미만 제외
- 동일 섹터 최대 3종목
- 최종 Top 10 반환

### 4. API 구조

`app.main`은 설계안의 3개 API를 그대로 스캐폴딩합니다.

- 일별 후보 조회
- 종목별 신호 요약
- 백테스트 요약

## 현재 의도적으로 비워둔 부분

아직 실제 데이터/운영 구현은 넣지 않았습니다.

- EOD 시세 수집기
- DART/KIND/뉴스 수집기
- DB 영속화 리포지토리
- 장마감 후 배치 스케줄러
- 실제 백테스트 계산 엔진
- 웹 대시보드
