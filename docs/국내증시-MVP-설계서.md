# 국내증시 MVP 수익확률 향상 시스템 설계안

## Summary
- 제품 포지션은 `매수 추천기`가 아니라 `내일 주목 후보 선별기`로 고정한다.
- 초기 MVP는 `장마감 기준 EOD`, `1~3거래일 단기 모멘텀`, `룰+가중치 점수형`, `웹 대시보드`로 구현한다.
- 사용자에게는 `상승확률 %`를 직접 노출하지 않고 `점수 + 선정 이유 + 위험 신호`를 제공한다.
- 성공 기준은 `일별 Top 10 후보 적중률`로 잡고, 무료/저비용 데이터로 먼저 검증한다.

## Implementation Changes
- 유니버스 정의:
  - KOSPI/KOSDAQ 보통주만 포함.
  - ETF, ETN, 우선주, 스팩, 관리종목, 거래정지 종목, 상장 60거래일 미만 종목은 제외.
  - 최근 20거래일 평균 거래대금 `10억원` 미만 종목은 제외.
- 일일 배치 파이프라인:
  - 매 영업일 `15:50 KST` 이후 시세, 공시, 뉴스, 시장경보 상태를 수집한다.
  - 종목별 피처를 계산한 뒤 점수를 산출하고 상위 후보를 저장한다.
  - 결과는 다음 거래일 장 시작 전 대시보드에 노출한다.
- 점수 엔진:
  - 총점은 `0~100점`.
  - `수급/거래대금 확대 25점`: 거래대금 비율, 거래량 비율, 최근 20일 대비 확장 여부.
  - `종가 강도 20점`: 당일 고가-저가 범위 내 종가 위치, 윗꼬리 과다 여부.
  - `재료/이벤트 20점`: DART 공시, 실적, 계약, 정책, 업황 뉴스 등 신뢰 가능한 촉매 존재 여부.
  - `섹터 동조성 15점`: 동종 섹터 내 동반 상승 종목 수, 섹터 거래대금 증가.
  - `추세 연속성 10점`: 최근 3거래일 수익률과 당일 급등 전 선행 움직임.
  - `리스크 패널티 -30점까지`: 투자주의/경고/위험, 스팩/테마 과열, 풍문성 뉴스, 장대 윗꼬리, 과도한 갭상승, 변동성 과열.
- 후보 선정 규칙:
  - 상위 점수순으로 `Top 10` 노출.
  - 동일 섹터는 최대 `3종목`까지만 허용해 쏠림을 방지.
  - 리스크 패널티 적용 후 `60점 미만`은 후보에서 제외.
- 사용자 노출 방식:
  - 각 후보에 `총점`, `선정 이유 3개`, `위험 신호 2개`, `관련 뉴스/공시 링크`, `섹터`, `최근 거래대금 변화`를 표시.
  - 문구는 `내일 급등 예상` 대신 `내일 주목 후보`, `관심 필요`, `과열 주의`를 사용.
  - 화면 상단에 `투자 판단 책임 고지`, `지연시세 여부`, `마지막 갱신 시각`을 명시한다.

## Public APIs / Interfaces
- `GET /api/candidates/daily?date=YYYY-MM-DD`
  - 반환: `date`, `horizon=1-3d`, `generatedAt`, `candidates[]`
  - 각 후보: `rank`, `code`, `name`, `score`, `sector`, `reasons[]`, `riskFlags[]`, `newsLinks[]`, `disclosureLinks[]`
- `GET /api/stocks/{code}/signal-summary?date=YYYY-MM-DD`
  - 반환: `componentScores`, `rawFeatures`, `priceStats`, `liquidityStats`, `sectorStats`, `catalystSummary`
- `GET /api/backtests/summary?from=YYYY-MM-DD&to=YYYY-MM-DD`
  - 반환: `top10HitRate`, `medianMaxReturn`, `falsePositiveRate`, `sectorConcentration`, `warningHitRate`
- 내부 배치 출력 스키마:
  - `daily_candidate_scores(date, code, total_score, liquidity_score, close_strength_score, catalyst_score, sector_score, continuity_score, risk_penalty, reasons_json, risk_flags_json)`

## Test Plan
- 데이터 수집 테스트:
  - 시세, 공시, 뉴스, 시장경보 데이터가 누락될 때 배치가 실패하지 않고 해당 피처만 `null` 처리되는지 확인.
  - 동일 종목 코드 매핑과 중복 뉴스 제거가 정상 동작하는지 확인.
- 점수 엔진 테스트:
  - 거래대금 급증, 종가 강세, 공시 존재 시 점수가 올라가는지 검증.
  - 투자경고/위험 종목, 과도한 윗꼬리, 스팩 등은 패널티가 강하게 적용되는지 검증.
  - 동일 섹터 상위 종목이 3개 초과 시 컷오프가 적용되는지 확인.
- 백테스트 시나리오:
  - 최근 6개월 구간으로 일별 재생성하여 `Top 10 적중률`을 계산.
  - 적중 정의는 `후보 선정 다음 거래일 시가 기준, 3거래일 내 최고가 수익률이 +4% 이상`으로 통일.
  - 보조 지표로 `3거래일 내 -5% 이하 하락 비율`, `시장경보 편입 비율`, `섹터 편중도`를 함께 본다.
- UI 검증:
  - 후보 카드에 이유·위험·출처 링크가 모두 표시되는지 확인.
  - 장마감 전에는 전일 결과, 장마감 후 배치 완료 전에는 `업데이트 중` 상태가 노출되는지 확인.

## Assumptions
- 초기 MVP는 `실시간 체결/호가`, `자동매매`, `확률형 예측 수치`, `직접 매수/매도 추천`을 포함하지 않는다.
- 데이터는 무료/저비용 소스를 우선 사용하며, 기본 소스는 `EOD 시세`, `DART 공시`, `신뢰 가능한 뉴스/RSS`, `KIND 시장경보`다.
- 벤치마크 고도화는 2단계에서 진행한다.
  - 1단계: 룰+가중치 점수형 검증
  - 2단계: 충분한 이력 축적 후 로지스틱 회귀 등 경량 ML을 보조 점수로 추가
- MVP 목표는 `수익 보장`이 아니라 `허수 후보를 줄이고 설명 가능한 상위 후보를 안정적으로 추리는 것`이다.

## 중소형주 급등 신호 감지 설계

> 대상 유니버스: KOSPI/KOSDAQ 시가총액 **1,000억 원 이상** 보통주

### 신호 분류 및 세부 항목

#### 1. 거래량 신호 _(선행 지표, 최우선 감지 대상)_

| 신호 | 설명 | 임계값 |
|---|---|---|
| 거래량 급증 | 전일 대비 폭발적 거래량 증가 | 전일 대비 300% 이상 |
| 거래대금 돌파 | 20일 평균 거래대금 대비 급증 | 20일 평균의 5배 이상 |
| 장 초반 거래량 집중 | 09:00~10:00 집중 매수 | 일 평균의 50% 이상 초반 소화 |
| 공매도 감소 + 거래량 증가 | 숏커버링 + 신규 매수세 동반 | 공매도 비율 전주 대비 30% 감소 |

#### 2. 가격 패턴 신호

| 신호 | 설명 | 조건 |
|---|---|---|
| 박스권 돌파 | 장기 횡보 상단 돌파 | 횡보 기간이 길수록 돌파 강도 큼 |
| 52주 신고가 갱신 | 상방 저항선 없는 구간 진입 | 당일 종가 기준 |
| 갭 상승 시가 | 전일 종가 대비 갭업 출발 | 갭 +3% 이상 |
| 양봉 연속 | 연속 양봉 + 거래량 증가 동반 | 3일 이상 연속 양봉 |
| 눌림목 반등 | 상승 후 조정, 지지선 반등 | 5일선 or 20일선 지지 확인 |
| 동시호가 강세 | 아침 동시호가 매수잔량 우위 | 매수/매도 잔량 비율 2:1 이상 |

#### 3. 기술적 지표 신호

| 지표 | 급등 신호 조건 |
|---|---|
| RSI | 30 이하 과매도 탈출, 또는 50 돌파 후 70 미만 구간 (14일 기준) |
| MACD | 골든크로스 + 히스토그램 확대 (Signal선 상향 돌파) |
| 볼린저밴드 | 밴드 수축(스퀴즈) 후 상단 돌파, %B 지표 1.0 초과 |
| 이동평균선 | 5일 > 20일 > 60일 정배열 전환 시점 |
| 스토캐스틱 | 과매도 구간(20 이하) 탈출 후 %K·%D 골든크로스 |
| OBV | 주가 횡보 중 OBV 지속 상승 → 선행 매집 신호 |

#### 4. 수급/세력 신호

| 신호 | 설명 | 확인 방법 |
|---|---|---|
| 외국인/기관 순매수 | 중소형주에 기관 자금 유입 전환 | HTS 투자자별 매매동향 |
| 프로그램 매수 증가 | 차익/비차익 매수 동반 상승 | KRX 프로그램 매매 현황 |
| 대주주 자사주 매입 | 임원 자사주 매입 공시 | DART 공시 시스템 |
| 대차잔고 감소 | 공매도 세력 청산 진행 중 | 한국거래소 대차거래 현황 |

#### 5. 공시/이벤트 신호

| 신호 | 파급 강도 |
|---|---|
| 실적 서프라이즈 (예상치 대비 어닝 비트) | ★★★★★ |
| 신규 대형 계약 체결 공시 | ★★★★★ |
| 정부 정책/시사 이슈 테마 편입 | ★★★★ |
| KOSPI200·KRX300 지수 편입 예고 | ★★★★ |
| 최대주주 변경 / M&A 공시 | ★★★★ |
| 유상증자 철회 (악재 해소) | ★★★ |
| 특허 등록 / 기술 이전 공시 | ★★★ |

### 종목 스크리닝 조건 (자동화 적용)

```
[기본 필터]
- 시가총액: 1,000억 원 이상
- 거래량: 20일 평균 대비 500% 이상
- 당일 주가 변화: +3% 이상

[기술적 조건]
- RSI: 40 ~ 70 사이 (과매수 미진입 상태)
- 52주 최고가 대비: 80% 이상 회복 중
- 이동평균 정배열 여부: 5일 > 20일

[수급 조건]
- 외국인 or 기관 순매수 전환 (최근 3거래일)
- 공매도 비율: 전주 대비 30% 이상 감소

[제외 조건]
- 관리종목, 투자유의/경고/위험 종목 제외
- 최근 6개월 내 유상증자 이력 종목 주의
- 상장 60거래일 미만 종목 제외
```

### 자동화 구현 계획

#### 데이터 소스

| 도구 | 용도 |
|---|---|
| KIS Developers API | 실시간 시세·체결·호가 WebSocket 스트리밍 |
| pykrx | KRX 상장 종목 정보, 일별 OHLCV, 투자자별 현황 |
| FinanceDataReader | 주가 히스토리, 재무 데이터 |
| DART OpenAPI | 실시간 공시 수신 및 분류 |
| KIND (한국거래소) | 시장경보(투자주의·경고·위험) 상태 |

#### 배치 실행 흐름

```
[15:50 KST 장마감 후]
    ↓ pykrx / KIS API로 EOD 시세·거래량 수집
    ↓ DART OpenAPI로 당일 공시 수집
    ↓ 유니버스 필터링 (시총 1,000억 미만·관리종목·저유동성 제외)
    ↓ 신호별 피처 계산 (거래량비율, RSI, MACD, OBV 등)
    ↓ 스크리닝 조건 평가 → 후보 점수 산출
    ↓ Top 10 후보 DB 저장
[익일 장 시작 전 대시보드 노출]
```

#### 실시간 감지 (향후 확장)

```
[KIS WebSocket]
    ↓ 실시간 체결·호가 스트리밍
[신호 감지 엔진 (Python)]
    ↓ 거래량 임계값, 가격 패턴 실시간 판단
[알림 발송]
    ↓ Telegram Bot 또는 카카오 알림톡
```

#### 기술 스택

```python
# 핵심 라이브러리
pykrx               # KRX 시세·거래 데이터
FinanceDataReader   # 히스토리 데이터
pandas-ta           # 기술적 지표 (RSI, MACD, 볼린저밴드, OBV 등)
python-telegram-bot # 알림 발송
apscheduler         # 배치 스케줄링
```

### 리스크 및 주의사항

- 모든 신호는 참고 지표이며, 투자 손실 책임은 투자자 본인에게 있음.
- 중소형주는 유동성이 낮아 슬리피지 리스크가 크고, 급락 시 매도 지연 가능.
- 단일 신호보다 **3가지 이상 복합 조건**을 충족하는 종목을 우선 검토.
- 테마주·작전성 종목은 유사 신호가 나타날 수 있으므로 펀더멘털 검증 병행 필요.
- 화면 상단에 투자 판단 책임 고지, 지연시세 여부, 마지막 갱신 시각 명시 (기존 설계 기준 유지).
