# 📈 한국 주식 중소형주 급등 신호 감지 가이드

> 작성일: 2026-05-01  
> 대상: 한국 KOSPI/KOSDAQ 중소형주 (시가총액 1,000억 원 이상)

---

## 개요

중소형주는 대형주 대비 유동성이 낮아 특정 수급 변화가 발생할 경우 **단기 급등 패턴이 뚜렷하게 나타나는 경향**이 있습니다.  
아래 신호들을 복합적으로 조합하여 스크리닝하면 급등 후보 종목을 사전에 포착하는 것이 가능합니다.

---

## 1. 📦 거래량 관련 신호 _(가장 중요)_

거래량은 급등의 **선행 지표**로, 세력 개입 여부를 가장 직접적으로 나타냅니다.

| 신호 | 설명 | 임계값 예시 |
|---|---|---|
| **거래량 급증** | 전일 대비 거래량 폭발적 증가 | 전일 대비 300% 이상 |
| **거래대금 돌파** | 평균 거래대금 대비 급증 | 20일 평균의 5배 이상 |
| **거래량 이동평균 돌파** | 단기 평균 거래량 초과 | 20일 평균의 N배 초과 |
| **장 초반 거래량 집중** | 오전 9시~10시 내 집중 매수 | 일 평균의 50% 이상 초반 소화 |
| **공매도 감소 + 거래량 증가** | 숏커버링 + 신규 매수세 동반 | 공매도 비율 전주 대비 30% 감소 |

> [!IMPORTANT]
> 거래량 급증은 가격 상승보다 **1~2일 선행**하는 경우가 많습니다. 거래량 변화를 먼저 감지하는 것이 핵심입니다.

---

## 2. 📉 가격 패턴 신호

| 신호 | 설명 | 비고 |
|---|---|---|
| **박스권 돌파** | 장기 횡보 구간 상단 돌파 | 횡보 기간이 길수록 돌파 강도 큼 |
| **52주 신고가 갱신** | 강력한 모멘텀 신호 | 저항선 없는 상승 구간 진입 |
| **갭 상승 시가** | 전일 종가 대비 갭업 출발 | 3% 이상 갭업 |
| **양봉 연속** | 연속 양봉 + 거래량 증가 동반 | 3일 이상 연속 양봉 |
| **눌림목 반등** | 상승 후 조정, 지지선 반등 | 5일선 or 20일선 지지 확인 |
| **동시호가 강세** | 아침 동시호가 매수잔량 우위 | 매수/매도 잔량 비율 2:1 이상 |

---

## 3. 📊 기술적 지표 신호

| 지표 | 급등 신호 조건 | 비고 |
|---|---|---|
| **RSI** | 30 이하 과매도 탈출, 또는 50 돌파 | 14일 기준 |
| **MACD** | 골든크로스 + 히스토그램 확대 | Signal선 상향 돌파 |
| **볼린저밴드** | 밴드 수축(스퀴즈) 후 상단 돌파 | %B 지표 1.0 초과 |
| **이동평균선** | 5일 > 20일 > 60일 정배열 전환 | 정배열 완성 시점 |
| **스토캐스틱** | 과매도 구간(20 이하) 탈출 후 골든크로스 | %K, %D 교차 확인 |
| **OBV** | 주가 횡보 중 OBV 지속 상승 | 매집 진행 중 신호 |

> [!TIP]
> 단일 지표보다 **RSI + 거래량 + 이동평균선 정배열** 3가지 복합 조건을 충족하는 종목을 우선 검토하세요.

## 4. 💰 수급/세력 관련 신호

| 신호 | 설명 | 확인 방법 |
|---|---|---|
| **외국인/기관 순매수** | 중소형주에 기관 자금 유입 | HTS 투자자별 매매동향 |
| **프로그램 매수 증가** | 차익/비차익 매수 동반 상승 | KRX 프로그램 매매 현황 |
| **대주주 자사주 매입** | 임원 자사주 매입 공시 발생 | DART 공시 시스템 |
| **특정 계좌 집중 매수** | 상위 10개 계좌 집중 패턴 | HTS 투자자별 현황 탭 |
| **대차잔고 감소** | 공매도 세력 청산 진행 중 | 한국거래소 대차거래 현황 |

## 5. 📢 공시/이벤트 신호

| 신호 | 설명 | 파급 강도 |
|---|---|---|
| **실적 서프라이즈** | 예상치 대비 큰 폭 어닝 비트 | ⭐⭐⭐⭐⭐ |
| **신규 대형 계약 체결** | 매출 규모 대비 대형 계약 공시 | ⭐⭐⭐⭐⭐ |
| **테마 편입** | 정부 정책/시사 이슈 관련 테마 부각 | ⭐⭐⭐⭐ |
| **지수 편입 예고** | KOSPI200, KRX300 편입 예정 | ⭐⭐⭐⭐ |
| **최대주주 변경 / M&A** | 경영권 이슈, 인수합병 | ⭐⭐⭐⭐ |
| **유상증자 철회** | 악재 해소 후 반등 기대 | ⭐⭐⭐ |
| **특허 등록 / 기술 이전** | 신기술 관련 호재 공시 | ⭐⭐⭐ |

> [!NOTE]
> 공시 신호는 발생 즉시 반응하는 경우가 많으므로, DART OpenAPI를 활용한 **실시간 공시 모니터링** 자동화가 효과적입니다.

## 6. 🔍 종목 스크리닝 조건 (자동화 적용 예시)

```
[기본 필터]
- 시가총액: 1,000억 원 이상
- 거래량: 20일 평균 대비 500% 이상
- 당일 주가 변화: +3% 이상

[기술적 조건]
- RSI: 40 ~ 70 사이 (과매수 미진입 상태)
- 52주 최고가 대비: 80% 이상 회복 중
- 이동평균 정배열 여부: 5일 > 20일

[수급 조건]
- 외국인 or 기관 순매수 전환 (최근 3거래일)
- 공매도 비율: 전주 대비 30% 이상 감소

[제외 조건]
- 관리종목, 투자유의 종목 제외
- 최근 6개월 내 유상증자 이력 종목 주의
```

## 7. 🛠️ 자동화 구현 방법

### 데이터 수집

| 도구 | 용도 |
|---|---|
| **KIS Developers API** | 한국투자증권 실시간 시세/체결 데이터 |
| **FinanceDataReader** | 주가 히스토리, 재무 데이터 수집 |
| **pykrx** | KRX 상장 종목 정보, 일별 OHLCV |
| **DART OpenAPI** | 실시간 공시 수신 |

### 실시간 감지 아키텍처

```
[KIS WebSocket]
    ↓ 실시간 체결/호가 스트리밍
[신호 감지 엔진 (Python)]
    ↓ 조건 충족 여부 판단
[알림 발송]
    ↓ Telegram Bot / 카카오 알림톡
[대시보드]
    ↓ 감지 종목 리스트 시각화
```

### 추천 기술 스택

```python
# 핵심 라이브러리
pip install pykrx FinanceDataReader pandas ta python-telegram-bot

# 스케줄러 (매일 장 마감 후 스크리닝)
pip install schedule apscheduler
```

## 8. ⚠️ 주의사항

> [!WARNING]
> - 모든 신호는 **참고용**이며, 투자 손실에 대한 책임은 투자자 본인에게 있습니다.
> - 중소형주는 유동성이 낮아 **슬리피지 리스크**가 크고, 급락 시 매도가 어려울 수 있습니다.
> - 단일 신호보다 **3가지 이상 복합 조건**을 충족하는 종목을 검토하세요.
> - 테마주/작전주의 경우 신호가 유사하게 나타날 수 있으므로 **펀더멘털 검증**을 병행하세요.
